Wiring Diagram & ESP32 Pin Allocation
3.3V Logic Safe
GPIO4 → DS18B20 Data
Red to 3.3V, Black to GND, Yellow/White data to GPIO4. 4.7 kΩ resistor between Data and 3.3V.
GPIO14 → Reed Switch
Configured as INPUT_PULLUP. Other leg to GND. Closed = door shut.
GPIO21 & 22 → SSD1306 OLED
SDA to GPIO21, SCL to GPIO22, VCC to 3.3V, GND to GND. I2C address 0x3C (or 0x3D).
GPIO18 → Active Buzzer
Positive leg to GPIO18, negative to GND. Sounds on local out-of-range alarm.
GPIO25 & 26 → Green & Red LEDs
Green LED on GPIO25 (Normal). Red LED on GPIO26 (Alarm). Each with 220 Ω resistor.
GPIO34 → Mains Supply ADC
Voltage divider drops 5V mains line to ~2.5V into ADC. Below 1000 indicates power cut.
Complete ESP32 Firmware Core (Arduino C++)

Libraries required: OneWire, DallasTemperature, Adafruit_SSD1306, Adafruit_GFX, ArduinoJson.

#include <WiFi.h> #include <HTTPClient.h> #include <OneWire.h> #include <DallasTemperature.h> #include <Wire.h> #include <Adafruit_GFX.h> #include <Adafruit_SSD1306.h> #include <ArduinoJson.h> const char* WIFI_SSID = "Wokwi-GUEST"; // Or your 2.4 GHz phone hotspot const char* WIFI_PASS = ""; const char* API_URL = "http://YOUR-BACKEND-IP:3000/api/reading"; #define ONE_WIRE 4 #define DOOR_PIN 14 #define BUZZER 18 #define LED_OK 25 #define LED_BAD 26 const float T_MIN = 2.0, T_MAX = 8.0; OneWire ow(ONE_WIRE); DallasTemperature sensors(&ow); Adafruit_SSD1306 oled(128, 64, &Wire, -1); uint32_t lastSend = 0; void setup() { Serial.begin(115200); pinMode(DOOR_PIN, INPUT_PULLUP); pinMode(BUZZER, OUTPUT); pinMode(LED_OK, OUTPUT); pinMode(LED_BAD, OUTPUT); sensors.begin(); oled.begin(SSD1306_SWITCHCAPVCC, 0x3C); WiFi.begin(WIFI_SSID, WIFI_PASS); } void loop() { sensors.requestTemperatures(); float t = sensors.getTempCByIndex(0); bool doorOpen = digitalRead(DOOR_PIN) == HIGH; // HIGH = magnet away = open bool bad = (t > T_MAX || t < T_MIN); // Local failsafe alarm - operates independently of Wi-Fi! digitalWrite(LED_OK, !bad); digitalWrite(LED_BAD, bad); digitalWrite(BUZZER, bad); // Update 0.96" OLED display oled.clearDisplay(); oled.setTextColor(WHITE); oled.setTextSize(2); oled.setCursor(0, 0); oled.printf("%.1f C", t); oled.setTextSize(1); oled.setCursor(0, 30); oled.print(doorOpen ? "DOOR: OPEN" : "DOOR: closed"); oled.setCursor(0, 44); oled.print(bad ? "ALERT: out of range" : "Status: OK"); oled.display(); // Transmit telemetry every 10 seconds if (millis() - lastSend > 10000) { lastSend = millis(); if (WiFi.status() == WL_CONNECTED) { StaticJsonDocument<200> d; d["temp"] = t; d["door"] = doorOpen; d["mains"] = true; // In full build, read GPIO34 ADC d["uptime"] = millis() / 1000; String body; serializeJson(d, body); HTTPClient http; http.begin(API_URL); http.addHeader("Content-Type", "application/json"); http.POST(body); http.end(); } } delay(500); }
Wokwi Simulator Setup (30-Minute Virtual Build)
  1. Go to wokwi.com and start a new ESP32 project.
  2. Add parts: DS18B20, Slide Switch (stands in for the reed switch), SSD1306 OLED (I2C), Buzzer, and Two LEDs.
  3. Wire to the pins listed in the table above (GPIO4, GPIO14, GPIO21, GPIO22, GPIO18, GPIO25, GPIO26).
  4. Paste the Arduino firmware above. Wokwi includes simulated Wi-Fi (Wokwi-GUEST, no password).
  5. Drag the DS18B20 slider up/down and flip the slide switch to test every rule in real-time!
